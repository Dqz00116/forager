## Summary

把已验证的 LLM 驱动爬虫原型固化为可配置、可运行、有文档、有真实测试的 MVP CLI 工具。

## Requirement Reference

本特性对应需求 [REQ-f6985212](../requirements/REQ-f6985212.md)（pi-crawler MVP：LLM 驱动的探索式网页爬虫能力固化与文档化），其 9 条验收标准的精简版如下：

1. 配置 API key 与模型后，一条 CLI 命令即可对指定入口 URL 发起自主抓取，无需编写解析代码
2. 静态页面可抓取内容并抽取结构化记录（含可辨识的字段与值）
3. agent 能自主识别并跟随分页链接，连续抓取多页并汇总记录
4. 记录以 JSONL 格式持久化到本地文件，每行为一次解析即得的 JSON 对象（无双重编码）
5. 页面依赖客户端渲染时，可启用浏览器渲染兜底并成功抽取渲染后内容
6. 缺少 API key 或模型配置错误时，输出清晰的中文错误提示并正常退出
7. Ctrl+C 中断时正确清理浏览器等外部资源后再退出，不残留占用
8. 全部测试基于真实 LLM API（禁 mock），`npm test` 一条命令可运行且全部通过
9. 提供完整使用文档，覆盖安装、配置、运行方式与常见问题排查

## Key Decisions

本次需求澄清确定的关键决策：

- **(a) MVP 边界**：现有能力固化 + 文档化，不加新功能。
- **(b) 测试策略**：一律走真实 API，禁止使用 mock。
- **(c) LLM 接入**：走 OpenCode Go，模型为 muse-spark-1.3-contributor。
- **(d) 数据落盘**：JSONL 本地文件，不引入数据库。
- **(e) 范围排除**：反爬对抗与代理支持不在本期范围。
